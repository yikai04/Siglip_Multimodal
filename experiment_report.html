关键发现总结

1. 预训练视觉编码器是最大突破

Exp19 冻结 SigLIP ViT-B/16 后，t2i_R@1 从 36.65% 跃升至 47.36%，提升 10.71 个百分点。仅 12 个 epoch 即超过 Exp6 的 100 epoch 结果，证明预训练视觉特征是核心瓶颈。

2. Cosine Warmup 是最关键的超参优化

从 Exp0 到 Exp1，仅替换常数 LR 为 Cosine Warmup，t2i_R@1 从 21.26% 升至 29.83%，提升 8.57%。Warmup 防止初始不稳定，Cosine 衰减缓解过拟合。

3. Flickr8k 对增强策略极度敏感

RandomResizedCrop、RandAugment、TrivialAugment 均严重损害性能（分别降至 12.58%、24.69%、21.82%）。ColorJitter 仅在 mild(strength=0.2) 时有效，0.3 反而损害。

4. 更大模型容量在小数据上导致过拟合

width=64 (32.53%)、4L+8H+d512 (被终止)、MLP 投影头 (29.63%) 均不如 width=48。Flickr8k 30k 训练对只能支撑有限的模型容量。

CosineWarmupScheduler 核心代码

class CosineWarmupScheduler(torch.optim.lr_scheduler.LambdaLR): def __init__(self, optimizer, warmup_steps, total_steps, base_lr, min_lr_ratio=0.01): def lr_lambda(step): if step < warmup_steps: return step / max(1, warmup_steps) progress = (step - warmup_steps) / max(1, total_steps - warmup_steps) decay = 0.5 * (1 + math.cos(math.pi * progress)) return min_lr_ratio + (1 - min_lr_ratio) * decay # LR decays to min_lr, NOT to 0 super().__init__(optimizer, lr_lambda)

为什么 Cosine Warmup 有效

  • Warmup（10%总步数）：逐步从 0 提升到 base_lr，防止初期梯度过大导致训练崩溃
  • Cosine 衰减：后期参数更新幅度逐渐减小，精细优化嵌入空间
  • Min LR 下限（1%）：防止 LR 降至 0，训练末期仍有微量学习

为什么 width=48 有效

width=48 的 ResNet18 约 4.4M 参数（vs width=32 约 2.9M），1.5 倍的参数量提供了更丰富的视觉特征表示能力。在 Flickr8k 上，width=48 是模型容量与泛化的最佳平衡——width=64(Exp17) 反而过拟合。

为什么 mild ColorJitter 有效

ColorJitter(strength=0.2) 提供轻微颜色扰动而不破坏图像语义，让模型学习对颜色变化的不变性。但 strength=0.3(Exp16) 反而损害性能，说明 Flickr8k 对增强强度极其敏感。

  • 可学习参数变化：t 从初始 10.0 增至 62.59，b 从 -10.0 微调至 -10.57。t 远大于 Exp6 的 31.06，说明预训练视觉特征配合更大温度系数能更好区分正负样本

为什么 Exp19 是突破性改进

Exp0–18 的核心瓶颈是从头训练的 ResNet18 视觉特征质量有限。Flickr8k 仅 30k 训练对，不足以从头训练出高质量的图像特征提取器。冻结在海量数据上预训练的 ViT-B/16，直接获得高质量视觉特征，文本编码器只需学习如何将文本映射到与这些特征对齐的嵌入空间。

仅 12 个 epoch 就超越 Exp6 的 100 epoch 结果，充分验证了预训练视觉特征的价值。

损失函数 Bug 修复（影响所有实验）

关键发现

原始 loss.py 存在符号错误，导致训练 loss 约 200 倍高于正常值（204 vs 6.2 at epoch 1），模型几乎无法学习。

修复差异

- logits = -t * logits + b # 错误符号 - loss = labels * logits # 错误符号 + logits = t * logits + b # 正确，符合 SigLIP 论文 + loss = -labels * logits # 正确，符合 SigLIP 论文

修复后 epoch 1 loss 从 204 降至 6.2，模型恢复可训练性。此 bug 在所有实验开始前已修复。
